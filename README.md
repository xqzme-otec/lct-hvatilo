# lct-hvatilo
Решение команды Хватило для хакатона Лидеры Цифровой Трансформации, кейс Сервис искусственного интеллекта по оценке качества исследований
плотности костей человека

# Загрузка архива
Архив для загрузки содержит DICOM-исследования в формате .dcm, файлы ищутся по всему архиву, структура папок не важна

# Запуск docker compose
Для локального запуска
```sh
docker compose up -d --build
```
По умолчанию работает по адресу http://localhost
Для переопределения порта - в файле .env прописать
```
WEB_APP_PORT=8080
```

# Получение результатов
Интерфейс загрузки zip-архива с DICOM-файлами находится на главной странице портала из предыдущего пункта

Файлы ищутся по всему архиву, структура папок не важна

Результат - json, в котором содержатся подробная информация обо всех исследуемых зонах, основные интересующие поля:

1. Поле "annotated_zip_url" содержит URL на архив с результатом разметки изображения
2. Поле csv содержит строки для csv-файла
3. Поле "results" содержит подробную информацию по каждому исследованию

### Работа с моделью
В папке inference/ лежат скрипты запуска отдельных моделей:

- Поиск артефактов artifact.py
- Поиск рёбер vertebrae_with_rib.py
- Определение позвонков, сколиоза и угла укладки vertebrae.py
- Определение подвздошных костей crest.py

Работа с каждой из моделей описана внутри соответствующих функций
